3 rilis terverifikasi
v2.4.1 LATEST STABLE
18 September 2026

Peningkatan Telemetri SSE & Validasi Enkripsi Kredensial

Pembaruan pemeliharaan yang menstabilkan rekoneksi stream Server-Sent Events tanpa frame drop dan memperkuat enkripsi kunci provider LLM berbasis hardware AES-256-GCM.

Sorotan Perubahan:
  • • Telemetri SSE Fixed-Point: Penjaminan kalkulasi mikro-USD ($0.000001) presisi integer mutlak tanpa distorsi IEEE-754.
  • • Enkripsi Kredensial Envelope: Integrasi nonces 12-byte dan auth tag 16-byte pada kolom internal Postgres.
  • • Ukuran Biner Ringkas: Kompilasi Go 1.22 dengan flags pangkas simbol menghasilkan footprint biner mandiri tetap ~28 MB.
Perintah update:
curl -sSL https://get.agentdeck.dev/v2.4.1 | bash && agentdeck migrate
v2.4.0 STABLE
12 September 2026

Pondasi Telemetri Mikro-Dolar & Arsitektur Multi-Board

Peluncuran arsitektur orkestrasi mandiri yang mendukung multi-board Kanban dan Table view dengan ledger biaya presisi mikro-USD langsung ke database internal.

Sorotan Perubahan:
  • • Inisialisasi 21 Tabel Relasional: Migrasi otomatis skema PostgreSQL internal tanpa ketergantungan Redis atau Kafka.
  • • Gerbang Approval Interaktif: Pencegahan tindakan destruktif armada seperti eksekusi skrip root sebelum otorisasi pengguna.
  • • Format Dokumentasi Publik: Akses mandiri bebas autentikasi untuk developer dan tim integrasi.
Menjalankan daemon:
agentdeck serve --port=8080 --config=./agentdeck.yaml
