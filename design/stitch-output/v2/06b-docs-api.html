Referensi REST API

Spesifikasi resmi HTTP REST API internal bawaan daemon Go AgentDeck Core. Seluruh rute menggunakan port biner lokal http://localhost:8080/api/v1 dengan header autentikasi token Bearer.

Sumber Daya: Tasks

/api/v1/tasks

Operasi penjadwalan antrean pekerjaan armada agen AI, status komputasi, dan kalkulasi biaya ledger.

POST /api/v1/tasks
Peran minimum: member

Membuat task baru dan mengalirkannya ke backlog orkestrator daemon lokal untuk dieksekusi oleh worker yang ditugaskan.

Contoh Body Request application/json 
{
  "title": "Refactor auth module & telemetry pipeline",
  "board_id": "brd_sprint24",
  "assigned_agent": "agent-backend",
  "priority": "P0",
  "task_body": "Migrasi session state ke Postgres internal daemon.",
  "max_tokens_budget": 12000
}
Contoh Response (201 Created) application/json 
{
  "task_id": "task-771b",
  "status": "ready",
  "board_id": "brd_sprint24",
  "assigned_agent": "agent-backend",
  "priority": "P0",
  "created_at": "2026-09-18T14:10:00Z",
  "estimated_cost": 0.00
}
GET /api/v1/tasks/{id}
Peran minimum: viewer

Mengambil status rincian eksekusi task, identitas run aktif, jumlah token terkonsumsi, dan akumulasi biaya mikro-dolar.

Contoh Request (Headers) http 
GET /api/v1/tasks/task-771b HTTP/1.1
Host: localhost:8080
Authorization: Bearer adk_live_9b42f10c8e...
Accept: application/json
Contoh Response (200 OK) application/json 
{
  "task_id": "task-771b",
  "status": "running",
  "active_run_id": "run_9b42f1",
  "step_current": 2,
  "step_total": 4,
  "tokens": {
    "in": 31400,
    "out": 7200
  },
  "cost_usd": 0.3180
}

Sumber Daya: Runs

/api/v1/runs

Manajemen siklus hidup eksekusi runtime armada agen, pemantauan step-by-step, dan streaming telemetri Server-Sent Events.

POST /api/v1/runs
Peran minimum: member

Memicu siklus run agen otonom baru untuk task tertentu dengan konfigurasi timeout dan aturan approval gate.

Contoh Body Request application/json 
{
  "task_id": "task-771b",
  "agent_id": "agent-backend",
  "timeout_seconds": 1800,
  "require_approval_on": ["bash_exec", "db_migrate"]
}
Contoh Response (201 Created) application/json 
{
  "run_id": "run_9b42f1",
  "task_id": "task-771b",
  "status": "claimed",
  "agent_id": "agent-backend",
  "started_at": "2026-09-18T14:12:00Z",
  "stream_url": "/api/v1/runs/run_9b42f1/events"
}
GET /api/v1/runs/{id}/steps
Peran minimum: viewer

Mengambil riwayat langkah eksekusi dalam run, durasi latency, konsumsi token input/output, dan biaya komputasi presisi micro-USD.

Contoh Request (Headers) http 
GET /api/v1/runs/run_9b42f1/steps HTTP/1.1
Host: localhost:8080
Authorization: Bearer adk_live_9b42f10c8e...
Contoh Response (200 OK) application/json 
[
  {
    "step_index": 1,
    "step_name": "step_01_query",
    "tool_name": "read_file",
    "status": "COMPLETED",
    "duration_ms": 18200,
    "tokens_in": 1420,
    "tokens_out": 184,
    "cost_micros": 2800
  },
  {
    "step_index": 2,
    "step_name": "step_02_decompose",
    "tool_name": "model_invocation",
    "status": "RUNNING",
    "duration_ms": 46210,
    "tokens_in": 8940,
    "tokens_out": 2104,
    "cost_micros": 24200
  }
]

Sumber Daya: Agents

/api/v1/agents

Registrasi identitas model, binding kredensial provider LLM terenkripsi AES-256-GCM, dan verifikasi kapabilitas.

POST /api/v1/agents
Peran minimum: admin

Mendaftarkan worker agent baru ke daemon lokal. Kredensial API provider LLM dienkripsi sebelum disimpan ke tabel internal.

Contoh Body Request application/json 
{
  "name": "agent-security",
  "provider": "anthropic",
  "model": "claude-3-5-sonnet",
  "provider_api_key": "sk-ant-api03-...",
  "max_runtime_seconds": 3600,
  "skills": ["security_audit", "sbom_check"]
}
Contoh Response (201 Created) application/json 
{
  "agent_id": "agt_sec_884",
  "name": "agent-security",
  "provider": "anthropic",
  "model": "claude-3-5-sonnet",
  "status": "ACTIVE",
  "created_at": "2026-09-18T10:15:00Z"
}
GET /api/v1/agents
Peran minimum: viewer

Mengambil daftar seluruh armada agent terdaftar beserta status operasional (ACTIVE, UNCONFIGURED, ARCHIVED).

Contoh Request (Headers) http 
GET /api/v1/agents HTTP/1.1
Host: localhost:8080
Authorization: Bearer adk_live_9b42f10c8e...
Contoh Response (200 OK) application/json 
[
  {
    "agent_id": "agt_backend_01",
    "name": "agent-backend",
    "provider": "openai",
    "model": "gpt-4o",
    "status": "ACTIVE",
    "runs_completed": 36
  },
  {
    "agent_id": "agt_data_9a",
    "name": "agent-data",
    "provider": "deepseek",
    "model": "deepseek-coder",
    "status": "ACTIVE",
    "runs_completed": 14
  }
]

Sumber Daya: Approvals

/api/v1/approvals

Gerbang verifikasi manusia sebelum pemanggilan tool destruktif atau mutasi infrastruktur.

POST /api/v1/approvals/{id}
Peran minimum: admin

Mengesahkan atau menolak permintaan aksi berisiko tinggi yang tertahan di status awaiting_approval (misal: eksekusi script bash atau migrasi schema).

Contoh Body Request application/json 
{
  "decision": "approve",
  "reason": "Divalidasi pada staging environment.",
  "actor": "reza@core-platform.internal"
}
Contoh Response (200 OK) application/json 
{
  "approval_id": "appr_9b42f1",
  "status": "APPROVED",
  "signed_by": "reza@core-platform.internal",
  "action_released": "infra_cli drop_replica",
  "resumed_at": "2026-09-18T14:24:00Z"
}
