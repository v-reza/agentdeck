Skema Telemetri Run & SSE

Spesifikasi resmi stream Server-Sent Events (SSE) dan payload telemetri eksekusi run pada daemon lokal AgentDeck Core. Seluruh telemetri biaya dan token dihitung dengan presisi integer tetap tanpa deviasi floating point.

1. Skema Event Stream SSE (AC1)

Daemon memancarkan frame SSE pada endpoint streaming /api/v1/runs/{id}/events. Setiap baris stream mengikuti spesifikasi envelope berikut:

Field Tipe Sifat (AC3) Deskripsi
id integer Wajib Nomor urut sekuensial event (seq counter) untuk reconnect Last-Event-ID.
event string Wajib Nama event: step.started, step.finished, run.completed, run.failed.
retry integer Opsional Interval milidetik rekoneksi klien browser jika koneksi terputus (default: 3000ms).
data object (JSON) Wajib Payload objek data step atau run terstruktur sesuai spesifikasi di bawah.

2. Skema Payload Step (step.finished)

Struktur atribut di dalam objek data saat event penyelesaian langkah dipancarkan:

Nama Field Tipe Data Satuan Sifat (AC3) Keterangan
run_id string — Wajib UUID pengidentifikasi eksekusi run aktif.
step_index integer indeks Wajib Urutan langkah dalam run (0-indexed).
tool_name string — Dapat null Nama tool yang dieksekusi; bernilai null bila penalaran langsung.
tokens_input integer jumlah token Wajib Token prompt/instruksi yang dikirimkan ke model.
tokens_output integer jumlah token Wajib Token penyelesaian yang dihasilkan oleh model.
tokens_cached integer jumlah token Dapat null Token terbaca dari cache penyedia; bernilai null saat eksekusi dingin.
cost_micro_usd integer micro-USD Wajib Biaya komputasi step ($1 = 1.000.000 µUSD). Contoh: $0.00142 = 1420.
cumulative_cost_micro_usd integer micro-USD Wajib Total biaya terkumpul dari step awal hingga step saat ini.
latency_ms integer milidetik Wajib Lama eksekusi internal step dari pemanggilan hingga output parsing.
exit_code integer posix code Dapat null Kode return tool (0 = sukses). Bernilai null bila step bukan eksekusi CLI.
error_payload object (JSON) — Dapat null Eksplisit bernilai null jika langkah sukses; berisi kode kesalahan jika gagal.

3. Contoh Raw Frame SSE

Contoh payload mentah event step.finished yang diterima klien saat step berhasil diselesaikan: 

id: 1042
event: step.finished
retry: 3000
data: {
  "run_id": "run_9b42f1a0e88c",
  "step_index": 2,
  "tool_name": "postgres_query",
  "status": "COMPLETED",
  "tokens_input": 1280,              // tipe: integer, satuan: jumlah token
  "tokens_output": 164,              // tipe: integer, satuan: jumlah token
  "tokens_cached": null,             // tipe: integer, sifat: dapat bernilai null saat eksekusi dingin
  "cost_micro_usd": 1420,            // tipe: integer, satuan: micro-USD ($0.001420)
  "cumulative_cost_micro_usd": 27400,// tipe: integer, satuan: micro-USD ($0.027400)
  "latency_ms": 412,
  "exit_code": 0,
  "error_payload": null,             // sifat: eksplisit null karena step berakhir sukses
  "timestamp": 1726658402000
}

Pelajari cara menggunakan token ledger mikro-dolar pada aplikasi klien atau integrasikan webhook tanda tangan HMAC-SHA256 untuk pemantauan otomatis.
