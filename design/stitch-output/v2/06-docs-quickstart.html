Panduan Mulai Cepat

Inisialisasi pangkalan orkestrator AgentDeck di server atau workstation lokal Anda dalam hitungan menit. Seluruh komponen berjalan sebagai biner tunggal mandiri yang terhubung langsung ke PostgreSQL internal Anda.

01

Prasyarat Sistem

Pastikan PostgreSQL 14+ telah berjalan dan dapat diakses. Unduh biner tunggal AgentDeck sesuai dengan arsitektur sistem Anda (Linux x86_64, ARM64, atau macOS):

TERMINAL 
curl -sSL https://get.agentdeck.dev/v2.4 | bash
02

Migrasi Database

Inisialisasi 21 tabel relasional internal dan skema ledger audit telemetri mikro-dolar pada database PostgreSQL target:

TERMINAL 
agentdeck migrate --db-url="postgres://postgres:secret@localhost:5432/agentdeck?sslmode=disable"
03

Menjalankan Binary Daemon

Jalankan daemon biner AgentDeck Core. Perintah ini mengaktifkan antarmuka web, REST API pada port 8080, serta server ingest telemetri gRPC:

TERMINAL 
agentdeck serve --port=8080 --config=./agentdeck.yaml
04

Mendaftarkan Agent Pertama

Hubungkan worker agent otonom pertama Anda ke daemon dengan mendaftarkan slug identitas, model LLM target, dan kredensial akses provider:

TERMINAL 
agentdeck agent add --name="agent-backend" --provider=openai --model=gpt-4o

Langkah Selanjutnya

Setelah daemon berjalan dan agent terdaftar, pengguna dapat membuka dasbor web lokal di http://localhost:8080 atau melanjutkan dengan mengeksplorasi dokumentasi REST API dan konfigurasi gate approval.
