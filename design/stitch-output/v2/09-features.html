Kapabilitas Utama AgentDeck Core

Dibangun khusus untuk armada multi-agen dengan kendali penuh di infrastruktur Anda sendiri.

01

Telemetri Mikro-Dolar (Fixed-Point)

Pencatatan konsumsi token dan komputasi presisi hingga satuan mikro-USD ($1 = 1.000.000 µUSD). Mencegah distorsi floating-point IEEE-754 pada agregasi multi-langkah.

Toleransi deviasi: $0.00 Tabel Relasional
02

Approval Gates Interaktif

Mencegah pemanggilan tool destruktif seperti eksekusi bash atau migrasi skema database. Eksekusi armada dijeda secara otomatis hingga diverifikasi manusia melalui UI atau webhook.

Timeout TTL: 30 menit Diff Mutasi
03

Biner Tunggal Mandiri (~28 MB)

Kompilasi Go 1.22 ramping tanpa beban orkestrator kontainer rumit. Beroperasi stabil dengan konsumsi memori idle di bawah 80 MB pada server VPS lokal maupun cloud.

RAM Idle: < 80 MB Self-Hosted
Protokol & Keamanan Data

Enkripsi Kredensial AES-256-GCM & Stream SSE

Kredensial API provider LLM disimpan dengan enkripsi amplop perangkat keras (nonce 12-byte dan auth tag 16-byte). Telemetri langkah diekspos melalui stream Server-Sent Events (SSE) dengan dukungan rekoneksi Last-Event-ID otomatis.

Header: Last-Event-ID gRPC Port :8080 HMAC-SHA256 Signatures
