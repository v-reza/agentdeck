Frequently asked questions

Do I need Kubernetes? +
No. One binary and a Postgres connection string.
Where does my agent code run? +
On your machine. AgentDeck schedules and records; it does not execute your code.
Can I gate only some tools? +
Yes, per agent. Set the gate mode to require, auto, or off.
What happens when I hit a budget cap? +
The run stops with outcome budget_exceeded and the task goes back to ready. Nothing is silently dropped.
