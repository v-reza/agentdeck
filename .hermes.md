# AgentDeck — aturan kerja di repo ini

File ini auto-load tiap session Hermes yang cwd-nya di dalam repo ini.
Baca ini **sebelum** nulis kode. Kalau ada konflik dengan kebiasaan umum
(YAGNI, "lebih simpel", "versi minimal"), file ini yang menang.

## Dokumen kontrak

Baca dulu, ikuti — jangan cuma dibaca:

- `docs/OPEN-ISSUES.md` — **baca ini duluan.** Isu yang masih terbuka, tiap baris diverifikasi ulang ke kode. Ini pengganti `HANDOFF.md`
- `docs/OVERNIGHT-BRIEF.md` — **kalau run-nya unattended**, ini yang dibaca tiap turn: objective, urutan fase, gate, larangan
- `docs/OVERNIGHT-LOG.md` — append-only, satu entri per fase. Ditulis **sebelum** lanjut fase berikutnya
- `docs/ARCHITECTURE.md` — struktur, endpoint, skema, keputusan teknis
- `docs/DECISIONS.md` — keputusan final. **Mengalahkan** YAGNI/simplifikasi/preferensi
- `docs/DESIGN.md` — token design. Ini satu-satunya sumber token
- `docs/00-PRD.md` — story + acceptance criteria
- `design/stitch-output/v2/*.html` — sumber kebenaran **layout**, bukan teks

`archive/reports/*` = dokumen historis, **termasuk `HANDOFF-2026-09-21.md`** (status lama
provider registry + audit F3). **Jangan** dipakai sebagai sumber kebenaran.

Kemajuan nyata (endpoint mana yang jalan, modul mana yang belum) ada di
`ARCHITECTURE.md` §6.2 kolom `Status` **tabel detail §6.2.1–§6.2.19** dan §18.3.
**Jangan pakai ringkasan §6.2.20** — dia basi (bilang Runs 0/6 padahal detailnya
4 ✅ / 2 ⬜). Angkanya dihitung dari kode dan dijaga `tools/verify_suite.py`, jadi
jangan dipercaya ingatan.

Konflik antar dokumen: sebut konflik spesifiknya, pakai keputusan terbaru
sebagai arah operasional. **Jangan** selesaikan konflik dengan menunda,
motong scope, atau ngerjain versi kecil dulu.

## Gate berlapis — jangan pakai satu rigor buat semua

| Jenis kerjaan | Verifikasi | Biaya |
|---|---|---|
| Edit kapan saja | `tsc` + `prettier` | ~5 detik |
| Layout / CSS / design | screenshot **elemen** + ukur DOM. **Nol unit test.** | ~20 detik |
| Logic / business rule | test wajib. Bug fix → RED dulu | ~1 menit |
| Security guard | test + mutation | ~5 menit |
| Sebelum commit / 1× sehari | full suite (`e2e` + `vitest` + `go test`) | ~5 menit |

Full suite fungsinya **deteksi regresi silang**, bukan verifikasi kerjaan barusan.
Mutation testing cuma buat **security/business rule**. Jangan buat CSS.
Jangan jalanin full suite tiap iterasi UI — itu buang waktu tanpa nambah sinyal.

**Unattended (`/goal`)**: gate-nya `tools/gate-overnight.cmd` — gofmt + `go build` +
`tsc -b` + `vitest run` + `prettier --check src/`, terukur ~20-52 s. Plafon gate
Hermes dipatok **300 s dan nggak bisa dinaikin**, jadi `go test` **keluar** dari gate
(suite Go terukur ~490 s). Konsekuensinya: tiap fase, `go test` paketnya gw jalanin
**manual** dan hasilnya ditulis di `docs/OVERNIGHT-LOG.md`. Fase yang tidak dites
harus disebut di log — bukan didiemin.

`tools/gate.cmd` (punya sesi lain) isinya suite penuh 670 s → **mustahil** jadi gate.
Jangan dipakai buat `/goal`.

## Design match

Design = sumber kebenaran **layout**. Teks mockup (jargon spec) **jangan** dibawa
ke produk — ambil yang penting, buang yang nggak.

Clone token/warna/lebar **saja belum match**. Elemen yang bikin layar kebaca
adalah bagian dari design juga: **icon**, state visual (row archived =
strikethrough + background abu + border kiri), badge, empty state, divider.

Sebelum bilang sebuah layar kelar: bikin **inventory** — tiap elemen struktural
di design vs implementasi (ada / beda / **ilang**). Yang ilang harus disebut,
bukan didiemin. Lihat `docs/DESIGN-INVENTORY.md`.

## Larangan

- Jargon spec (`US-AD`, `AC`, `M1`–`M6`, `HTTP \d{3}`) **dilarang masuk UI yang
  dirender**. Komentar kode boleh. `/github` pengecualian.
- Jangan commit/push ke remote publik tanpa konfirmasi user.
- Jangan commit `node_modules`, build output, cache, screenshot sementara, secrets.
- Semua credential/token/password/connection string → `[REDACTED]`.
- **Jangan tulis nomor WA / JID / chatId di file mana pun di repo ini** (repo publik).
- Jangan pakai `window.location.pathname`, `window.alert()`, `confirm()`, `prompt()`.
- Worker/subagent dilarang jalankan `git checkout --`, `git restore`, `git stash`,
  `git reset`, `git clean`, `git revert`.

## Konvensi

**Go**: pgx v5, sqlc, PostgreSQL 16. `gofmt -l .` wajib kosong. Satu statement per baris.

**Frontend**: React Router v7. Redux Toolkit = satu-satunya state management,
RTK Query buat server state. Prettier wajib.

**Dropdown**: satu komponen `Combobox` buat semua select. Token design **wajib** —
jangan token bawaan browser.

**Modal**: role/ARIA, focus trap, Escape, scroll lock, return focus, ikut `DESIGN.md`.

**Error**: yang udah punya inline surface jangan diduplikasi jadi toast.

## Verifikasi — bukti, bukan klaim

- "Selesai" = ada bukti eksekusi nyata. Bukan build hijau, bukan demo jalan.
- Run test hijau **batal** kalau ada file berubah di jendela waktunya. Cocokin
  mtime file `src/`, `e2e/`, dan backend terhadap waktu mulai/selesai run.
- Batch exit code 0 **nggak** membuktikan sukses — baca log marker.
- `vision_analyze` nggak reliabel buat full-page screenshot. Pakai screenshot
  **elemen** atau ukur DOM.
- Mutation yang gagal-build **bukan** CAUGHT yang sah.
- Kalau 404 dari route yang mestinya ada: cek **artifact yang jalan** (image
  container) dulu, bukan source. Rebuild sebelum nyari bug kode.

## Unattended (overnight / `/goal`)

- Kontrak run: `docs/OVERNIGHT-BRIEF.md`. Jejak: `docs/OVERNIGHT-LOG.md`.
- **Satu fase = satu commit + push + satu entri log.** Commit tengah malam itu
  checkpoint: sesi mati di fase 5, fase 1–4 tetap kepakai.
- Push ke `origin/main` **diizinkan** di mode ini (user sudah menyetujui). Verifikasi
  push cuma sah lewat `git ls-remote origin refs/heads/main` (server-side), bukan cache lokal.
- Urutan tiap fase: baca kontrak modul → kode → `go test` paket itu → migrasi →
  mutation kalau security/business rule → rebuild container → probe lawan API nyata
  kalau ada endpoint baru → commit → push → WA.
- Dispatcher AgentDeck tetap **OFF** (`AGENTDECK_DISPAT` tidak di-set). Jangan
  dinyalain tanpa instruksi eksplisit — tick yang hidup membelanjakan kredensial user.
- Watchdog: cron `agentdeck-overnight-watchdog` (10 menit, `--no-agent`) membaca state
  goal sesi ini dan mengirim WA kalau goal berhenti atau mandek. Cron **cuma lapor**,
  dia tidak me-resume sesi CLI — jangan menjanjikan resume.
